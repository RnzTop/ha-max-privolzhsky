# MAX — Техцентр Приволжский

Заявка на обратный звонок внутри MAX: имя из профиля и телефон. Получатель — закрытая рабочая группа, указанная в `staff_chat_id`. В меню только запись и контакты.

После обновления настройте рабочую группу на вкладке «Конфигурация». Как получить её ID — на вкладке «Документация». Токен остаётся в HA. Для постоянной работы нужен Webhook.
