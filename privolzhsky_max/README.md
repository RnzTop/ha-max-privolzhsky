# MAX — Техцентр Приволжский

Локальное приложение Home Assistant Supervisor для aarch64. Откройте вкладку «Документация» для установки и настройки. Введите токен только в конфигурации приложения. По умолчанию включён режим polling для проверки; постоянная работа требует Webhook с публичным HTTPS на 443.

Меню: запись на сайте, услуги и цены, частые вопросы, контакты. Только личные диалоги, без ИИ и сбора контактов.
