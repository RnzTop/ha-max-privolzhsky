# MAX — Техцентр «Приволжский»

Приложение Home Assistant Supervisor для Raspberry Pi aarch64. Версия **1.1.0**.

Меню: **«Записаться на ремонт»** и **«Контакты»**. Имя берётся из профиля MAX, клиент вводит только телефон. После проверки и подтверждения заявка направляется в закрытую рабочую группу MAX. Услугу и время сотрудник уточняет при звонке.

## Установка без файлового менеджера

В Home Assistant откройте **Настройки → Приложения → Магазин → ⋮ → Репозитории** и добавьте:

```text
https://github.com/RnzTop/ha-max-privolzhsky
```

Найдите «MAX — Техцентр Приволжский» → «Установить». Supervisor соберёт образ на устройстве.

## Обновление

Магазин → ⋮ → «Проверить обновления», затем обновите приложение до 1.1.0. Токен и база сохраняются, удалять приложение не нужно. Новый токен в репозиторий не добавляйте.

## Рабочий чат

1. Включите `setup_mode` в конфигурации HA и перезапустите приложение.
2. Добавьте бота в закрытую рабочую группу; её ID появится в журнале HA. Если бот уже добавлен, команда `/chatid` в группе при достаточных правах вернёт её ID.
3. Вставьте ID целиком в `staff_chat_id`, выключите `setup_mode`, сохраните и перезапустите.
4. В личном диалоге отправьте `/start` и проверьте заявку с собственным телефоном.

Полная [инструкция](privolzhsky_max/DOCS.md) объясняет права группового бота, ошибки доставки, хранение и Webhook. Пока рабочая группа не настроена, телефон не собирается. Для постоянной работы MAX требует Webhook с публичным HTTPS на 443; Long Polling предусмотрен для проверки.
