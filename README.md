# MAX — Техцентр «Приволжский»

Репозиторий приложения Home Assistant Supervisor для Raspberry Pi 4 (aarch64).

## Установка по ссылке

В Home Assistant: **Настройки → Приложения → Магазин → ⋮ → Репозитории**. Добавьте ссылку: https://github.com/RnzTop/ha-max-privolzhsky. Найдите «MAX — Техцентр Приволжский» и нажмите «Установить». Supervisor соберёт образ на устройстве. Файловый менеджер и ручной запуск Docker не нужны.

В конфигурации приложения введите токен MAX. Режим polling подходит для первой проверки; для постоянной работы требуется Webhook с публичным HTTPS на порту 443. Полная инструкция находится на вкладке «Документация» приложения.

Токены и персональные настройки в репозиторий не загружаются.
